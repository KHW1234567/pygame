# 🛡️ 강철폐포부대 (Steel Alveoli Unit)

> **호흡기를 위협하는 오염물질에 맞서 싸우고 몸속 산소포화도를 지키는 디펜스 슈팅 게임!**  
> Pygame으로 구현된 레트로 스타일의 탄막/디펜스 슈팅 게임으로, 플레이어는 폐를 보호하는 '폐포 병사'가 되어 유해 먼지, 고지방 음식, 담배 연기, 그리고 강력한 보스들로부터 산소 수치를 방어해야 합니다.
---

## 🎮 게임 개요 (Game Overview)

* **목표**: 제한 시간 **60초** 동안 산소포화도(SpO2)를 **90% 이상**으로 유지하며 생존하십시오.
* **패배 조건**:
  1. 산소포화도가 **0%**로 떨어지는 경우
  2. 보유한 폐포 병사가 **모두 소멸**하는 경우
  3. 적군 또는 보스가 **화면 최하단에 도달**하는 경우
* **특징**: 시간이 흐를수록 적들의 체력이 점차 강해지며(초당 +0.15), 특정 시점마다 강력한 거대 보스가 출현합니다.

| :--- | :--- |
| **`←` / `→` (방향키)** | 폐포 부대 전체를 좌우로 이동시킵니다. |
| **`Spacebar` (스페이스바)** | 현재 대열에 합류한 모든 폐포 병사가 일제히 상단으로 총알을 발사합니다. |

## 🎖️ 게임 규칙 및 시스템 (Systems)

### 1. 산소포화도 (SpO2) 시스템
* 게임 시작 시 **100%**로 시작하며, 1초마다 **5%씩 자연 감소**합니다.
* 적을 처치할 때마다 일정량의 산소포화도가 회복됩니다.
* 제한 시간 종료 시 산소포화도가 **90% 이상**이어야 게임 클리어(성공)가 가능합니다.

### 2. 동적 스쿼드 시스템 (브로콜리 스택)
* 아이템 **브로콜리**를 획득할 때마다 새로운 폐포 병사가 부대에 추가됩니다 (최대 30명).
* 병사들은 한 줄에 최대 10명까지 배치되며, 10명이 초과되면 윗줄로 겹쳐 쌓여 더 강력한 집중 화력을 낼 수 있습니다.
* 적과 부딪히면 충돌한 병사가 즉시 소멸하므로 대열 관리가 중요합니다.

## 👾 적군 및 보스 정보 (Enemies & Bosses)

### 일반 적군 (시간이 지날수록 체력이 초당 0.15씩 증가합니다)
* **먼지 (Dust)**
  * **기본 체력**: 1
  * **이동 속도**: 2.0 (빠름)
  * **처치 시 효과**: 점수 +1 / SpO2 +1% 회복
* **고지방/고당분 음식 (Fast Food)**
  * **기본 체력**: 2 (10초 이후부터 스폰)
  * **이동 속도**: 1.5 (보통)
  * **처치 시 효과**: 점수 +6 / SpO2 +3% 회복
* **담배 (Cigarette)**
  * **기본 체력**: 4 (15초 이후부터 스폰)
  * **이동 속도**: 1.0 (느림)
  * **처치 시 효과**: 점수 +10 / SpO2 +5% 회복

### 보스 (Boss)
게임 시작 후 **20초**에 최초 등장하며, 이후 **15초 간격**으로 최대 3번 등장합니다. 보스가 등장할 때는 화면이 붉게 깜빡이며 경고음이 발생합니다.
* **보스 1**: 체력 `100` | 점수 `+100` | SpO2 `+10%`
* **보스 2**: 체력 `200` | 점수 `+100` | SpO2 `+10%`
* **보스 3**: 체력 `300` | 점수 `+100` | SpO2 `+10%`
* *보스는 플레이어와 부딪히면 병사 1명을 처치하고 보스 자신의 체력이 5 감소합니다.*

## 🚀 시작하기 (How to Run)

### 1. 필수 프로그램 설치
이 게임을 실행하려면 파이썬(Python 3.x)과 **Pygame** 라이브러리가 설치되어 있어야 합니다.

```bash
pip install pygame
```

### 2. 게임 실행
리포지토리를 클론한 후, 해당 폴더로 이동하여 `game.py`를 실행합니다.

```bash
python game.py
```

## 💻 기술적 특징 (Technical Details)
1. **해상도 자동 조절**: 플레이어의 모니터 해상도를 분석하여 최적의 비율(전체 크기의 80%)로 화면 크기를 동적으로 스케일링합니다.
2. **외곽선 렌더링**: 인게임 텍스트의 가독성을 높이기 위해 8방향 외곽선 텍스트 렌더링 함수(`draw_txt`)를 구현하였습니다.
3. **리소스 예외 처리**: 사운드나 이미지 리소스가 누락되더라도 게임이 튕기지 않고 검은색 더미 서피스 등으로 예외 처리가 되어 있어 비정상 종료를 최소화합니다.
